# Terço

Website para rezar o terço de forma simples, acessível e offline-first. Funciona em desktop e mobile; após o primeiro acesso, funciona sem internet.

## Stack

- **Next.js 14** (App Router, TypeScript)
- **Tailwind CSS**
- **PWA** com Workbox (Service Worker via `next-pwa`)
- Persistência local via `localStorage`

## Desenvolvimento

```bash
cd frontend
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
